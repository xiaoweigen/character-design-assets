# DeepSeek 大肥鱼／鲸鱼娘 · 设定图资源库

这里放我在 DeepSeek 社区“大肥鱼／鲸鱼娘”（吃白饭的蓝色大肥鱼）相关设计基础上继续改编的设定图，包括 Q 版六视图、古风服装与发型，以及佩剑、长枪两套角色设定。

欢迎拿去做非商业二创、绘画参考或视频创作。作品使用 AI 辅助制作，相关角色与前序设计的作者署名见下方。本项目为个人非官方同人资源库。
